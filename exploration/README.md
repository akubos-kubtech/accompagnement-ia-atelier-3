# Zone d'exploration architecturale (TP)

> Cette zone contient les templates pour les 4 étapes d'exploration que les participants
> réaliseront en s'appuyant sur l'IA durant l'atelier.

## Etapes

1. **[Cartographie des flux inter-modules](flux-inter-modules.md)** - Identifier les échanges de données entre domaines
2. **[Zones de friction](zones-friction.md)** - Détecter les entités partagées et les incohérences
3. **[Matrice de dépendances](matrice-dependances.md)** - Séquencement d'implémentation
4. **[Questions d'arbitrage](questions-arbitrage.md)** - Points à valider avec le client

## Prérequis

L'exploration s'appuie sur les artefacts produits dans :
- `00-contexte/` : glossaire, cartographie existante
- `domaines/` : spécifications, entités et règles par domaine
- `exigences-transverses/` : contraintes techniques et non-fonctionnelles
