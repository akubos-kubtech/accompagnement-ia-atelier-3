# Zone d'exploration architecturale (TP)

> Cette zone contient les 4 étapes d'exploration que les participants
> réaliseront en s'appuyant sur l'IA durant l'atelier.

## Etapes

1. **[Cartographie des flux inter-modules](flux-inter-modules.md)** - 36 flux identifiés (18 opérationnels + 6 référentiels + 12 externes) + 7 dépendances cachées
2. **[Zones de friction](zones-friction.md)** - 7 entités divergentes + 7 référentiels problématiques + 8 intégrations implicites
3. **[Matrice de dépendances](matrice-dependances.md)** - Matrice 7×7, chemin critique, séquencement en 5 phases + vagues géographiques
4. **[Questions d'arbitrage](questions-arbitrage.md)** - 6 incohérences SF + 7 flux manquants + 10 hypothèses à valider avec le client

## Prérequis

L'exploration s'appuie sur les artefacts produits dans :
- `00-contexte/` : glossaire, cartographie existante, acteurs/rôles, volumétries, intégrations, référentiels transverses
- `domaines/` : spécifications, entités et règles par domaine (7 domaines × 3 fichiers)
- `exigences-transverses/` : contraintes non-fonctionnelles, techniques et sécurité/conformité

## Comment utiliser cette zone durant l'atelier

Les participants peuvent utiliser ces fichiers de deux manières :
1. **Comme référence** : consulter les analyses pré-remplies pour alimenter leurs propres réflexions
2. **Comme point de départ pour prompter l'IA** : reprendre les constats et demander à l'IA d'approfondir, de challenger ou de proposer des alternatives
