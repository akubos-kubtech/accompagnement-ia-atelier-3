# Glossaire

> Termes, acronymes et définitions issus du CDC (sections 1.4 et Annexe H) et enrichis lors de l'analyse.

## Acronymes techniques

| Terme | Définition | Domaine(s) concerné(s) |
|-------|-----------|----------------------|
| API | Application Programming Interface - Interface de programmation applicative | Transversal |
| BI | Business Intelligence - Informatique décisionnelle | Reporting |
| CRM | Customer Relationship Management - Gestion de la relation client | CRM & Marketing |
| EDI | Electronic Data Interchange - Échange de données informatisé | Achats, Supply chain |
| ERP | Enterprise Resource Planning - Progiciel de gestion intégré (PGI) | Transversal |
| ESB | Enterprise Service Bus - Bus de services d'entreprise | Architecture |
| MFA | Multi-Factor Authentication - Authentification multi-facteurs | Sécurité |
| PCA / PRA | Plan de Continuité / Reprise d'Activité | Infrastructure |
| PIM | Product Information Management - Gestion des informations produits | Produits (transversal) |
| PoC | Proof of Concept - Démonstration de faisabilité | Projet |
| RGPD | Règlement Général sur la Protection des Données | Conformité |
| RTO / RPO | Recovery Time / Point Objective - Délai / Point de reprise objectif | Infrastructure |
| SaaS | Software as a Service - Logiciel en tant que service | Architecture |
| SLA | Service Level Agreement - Accord de niveau de service | Contractuel |
| SKU | Stock Keeping Unit - Unité de gestion de stock (référence article) | Stocks |
| SSO | Single Sign-On - Authentification unique | Sécurité |
| TCO | Total Cost of Ownership - Coût total de possession | Finance projet |
| UAT | User Acceptance Testing - Recette utilisateur | Projet |
| WMS | Warehouse Management System - Système de gestion d'entrepôt | Stocks & Entrepôts |
