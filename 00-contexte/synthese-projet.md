## Objectifs stratégiques

### Ambitions 2030

- **CA cible** : 4,5 Mds € (vs 2,8 en 2025)
- **E-commerce** : 40% du CA (vs 28%)
- **Expansion** : Europe de l'Est, Asie (50 points de vente en Asie)
- **Points de vente** : 600 (vs 347)
- **Pays** : 25 (vs 15)

### Ambitions métiers (projet Phoenix)

- Réduire de **30%** le temps consacré aux tâches administratives répétitives
- Réduire le **taux de rupture** en magasin (actuellement 4,2%, manque à gagner 35 M€/an)
- Réduire le **stock dormant** (actuellement 8% de la valeur totale)
- Accélérer le cycle **order-to-cash** : de 5,2 jours à 3 jours max (e-commerce)
- **Vision client 360°** unifiée tous canaux
- Intégrer une nouvelle filiale en **< 6 mois**
- Développer de nouveaux services : location mobilier, décoration sur-mesure, marketplace créateurs

### Objectifs techniques

- **Modernisation** : architecture Cloud native, SaaS privilégié
- **Rationalisation** : réduire de 40% les 45+ applications actuelles
- **Interopérabilité** : API robustes, intégration via ESB MuleSoft
- **Sécurité** : ISO 27001, SOC 2 Type II, chiffrement bout en bout
- **Performance** : < 2s pour 95% des transactions, x2 volumes à 2030
- **Autonomie métier** : paramétrage accessible aux key users sans IT
